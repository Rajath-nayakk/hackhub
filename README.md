# 🚀 HackHub

> A platform that helps engineering students discover hackathons, learn from winning projects, find teammates, and prepare for upcoming competitions.

## 🎯 About

HackHub is a full-stack platform designed for engineering students to discover and participate in hackathons.

It brings hackathon opportunities, previous winning projects, team building, recommendations, and preparation tools into one place.

## ✨ Planned Features

- 🔎 Discover upcoming hackathons
- 📅 Track registration deadlines
- 📍 Find nearby and online hackathons
- 🏷️ Filter by technology and domain
- 🏆 Explore previous winning projects
- 👤 Student profiles
- ⭐ Bookmark hackathons
- 🔔 Deadline notifications
- 👥 Find teammates
- 🤖 AI-powered project and idea assistance
- 📊 Hackathon trends and insights
- 🛠️ Admin dashboard
